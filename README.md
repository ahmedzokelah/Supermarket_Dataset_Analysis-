My Contributions
Graphical User Interface (GUI)
I developed the interactive interface that allows users to input parameters and visualize results. my GUI enables:
•	User input for dataset path, number of clusters, and parameters for association rules.
•	Dynamic updates displaying data visualization results.
•	An intuitive dashboard integrating all visualizations for easy interpretation.
Data Cleaning & Assessment
I ensured the Grocery (GRC) dataset was well-structured and ready for analysis by:
•	Identifying missing or inconsistent data and applying necessary preprocessing.
•	Standardizing attributes to maintain consistency across records.
•	Filtering out anomalies to improve model accuracy.
K-Means Clustering
I implemented K-Means clustering to segment customers based on their spending behavior and age. my role included:
•	Preprocessing data for optimal clustering performance.
•	Selecting a suitable number of clusters and validating results.
•	Displaying cluster assignments in a structured table.
